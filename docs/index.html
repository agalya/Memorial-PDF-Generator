🖥️ Memorial PDF Generator

Create elegant memorial PDFs with your poem and photos

Transform your cherished memories into beautifully formatted memorial PDFs. Whether you're honoring a loved one with a poem or creating a lasting tribute, our Memorial PDF Generator makes it easy.

✨ Features

  • Create elegant memorial PDFs
  • Customize with your own photos
  • Add poems and text tributes
  • Choose single or multi-column layouts
  • Professional formatting
  • Support for multiple languages
⚠️ Note: The app backend needs to be deployed to a service like Render.com. See the GitHub repository for deployment instructions.
🚀 Launch App 📦 GitHub Repo

📖 Quick Setup

For local use:

git clone https://github.com/agalya/Memorial-PDF-Generator.git
cd Memorial-PDF-Generator
pip install -r requirements.txt
python app.py

Then open http://localhost:5000 in your browser.
